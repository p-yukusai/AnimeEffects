What changed from the current panel

One value, one place

Default Keys and Current Keys disappear. Sections are for groups of related settings; a single property is a ROW, not a collapsible section. The row shows the value at the playhead. Editing follows model 2: a static property changes its base value; an animated property creates/updates a key at the current frame.

Key state is visible

The affordance is the timeline's dot, not a second diamond vocabulary:
no keys, editing changes the static value.
keyed at this frame.
animated between keys.

Filters stay a stack

Filter order, mute, remove, and the searchable add action live here, not as top-level HSV/Blur property sections.

Auto-key verdict

The recommended variant has no global Auto-key. In model 2, animation is already auto-keyed once a property is animated; a global “off” would make edits to animated values ambiguous or non-persistent. Blender’s toggle is a power mode with a loud warning state; add it later only if a real workflow demands it.
